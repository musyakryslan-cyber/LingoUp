# Налаштування Supabase для LingoUp

GitHub Pages хостить сторінки сайту, а Supabase забезпечує автентифікацію та базу профілів.

1. Відкрийте свій проєкт на [supabase.com](https://supabase.com/).
2. У Supabase відкрийте **SQL Editor**, вставте вміст `supabase/schema.sql` і виконайте запит. Якщо схема вже виконувалася раніше, запустіть оновлений SQL повторно — він додасть колонку типу користувача, дозвіл на редагування власного типу, таблиці відгуків і контактів адміністратора.
3. URL проєкту і **Publishable key** уже внесено в `supabase-config.js`. Publishable key призначений для браузера; ніколи не вставляйте `service_role` key у файли сайту.
4. У **Authentication → URL Configuration** додайте до **Site URL** адресу GitHub Pages:
   `https://musyakryslan-cyber.github.io/LingoUp/`
   За потреби додайте цю адресу і сторінки входу/реєстрації до **Redirect URLs**.
5. Зареєструйте акаунт адміністратора на сайті та підтвердьте електронну пошту, якщо підтвердження ввімкнене.
6. У SQL Editor призначте свій акаунт адміністратором, підставивши його email:

   ```sql
   update public.profiles
   set is_admin = true
   where id = (
       select id from auth.users
       where email = 'YOUR_ADMIN_EMAIL'
   );
   ```

7. Після виконання SQL і призначення адміністратора перевірте реєстрацію, вхід і адмінпанель на опублікованому сайті.

Таблиця профілів захищена RLS: користувач читає власний профіль, адміністратор може читати всі профілі. Користувач може змінювати лише свій тип акаунта; адмінські права й інші профілі змінити з кабінету не можна. Паролі зберігає Supabase Auth, вони не потрапляють до таблиці профілів. Під час реєстрації можна вибрати «Студент» або «Учитель», а тип можна змінити в особистому кабінеті; для вже наявних профілів нова колонка матиме значення «Студент». Старі акаунти з локального `users.json` автоматично не переносяться — їх потрібно створити заново через форму реєстрації.

Відгуки доступні для читання всім відвідувачам, але публікувати їх можуть лише авторизовані користувачі. На сторінці показуються ім'я та перша літера прізвища автора, тип акаунта і текст відгуку. Повторно виконайте актуальний `supabase/schema.sql`, щоб створити таблицю та політики доступу до відгуків.

Адміністратор може додавати публічні контакти в адмінпанелі. Для посилань використовуйте `https://...`, для електронної пошти — `name@example.com`, для телефону — номер із кодом країни; відвідувачам ці значення показуються клікабельними.
